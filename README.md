# FixpowerLP

# このディレクトリ上にあるcode.jsの説明
この Google Apps Script は、Fix Power のお問い合わせフォーム用バックエンドです。フォームから送信された内容を受け取り、Google スプレッドシートに保存します。必要に応じて、管理者へ通知メールを送信します。

主な動作

フォーム送信時に、name、email、company、tel、prefecture、city の必須項目をチェックします。不足がある場合はエラーを返し、問題がなければ送信内容をスプレッドシートに追記します。保存先のシートが存在しない場合は自動作成されます。

保存される項目は、送信日時、氏名、メールアドレス、会社名、電話番号、都道府県、市区町村、メッセージ、送信元ページ URL、ユーザーエージェントです。

また、ADMIN_EMAIL が設定されている場合は、問い合わせ内容を管理者宛にメール通知します。簡易的なスパム対策として、ハニーポット項目 company_hp に値が入っている送信は無視する仕様です。

補足

現在、問い合わせ者本人への自動返信メール機能はコード内にありますが、コメントアウトされているため動作しません。現時点で有効なのは、スプレッドシート保存と管理者通知メール送信です。
